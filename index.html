1Configuración de autenticación de API

          

            
Crear aplicación conectada

            
    
              
  1. Navegar a Configuración → Aplicaciones → Gestor de aplicaciones
    2. 
              
  2. Hacer clic en Nueva aplicación conectada
    3. 
              
  3. Habilitar configuraciones de OAuth
    4. 
              
  4. Agregar scopes de OAuth: Acceso completo (full), Realizar solicitudes en cualquier momento (refresh_token)
    5. 
              
  5. Guardar y copiar clave de consumidor y secreto
    6. 
              
  6. Obtener token de seguridad desde tu correo electrónico o Configuración → Configuración personal → Restablecer token de seguridad
    7. 
            

            

              Flujo de autenticación: OAuth 2.0 con flujo de nombre de usuario y contraseña o JWT bearer token flow para server-to-server.
            

            

              
              
BASE_URL: https://your-instance.salesforce.com
AUTH_URL: https://login.salesforce.com/services/oauth2/token
API_VERSION: v59.0

OAUTH CREDENTIALS:
client_id: {consumer_key}
client_secret: {consumer_secret}
username: {your_email}
password: {password}{security_token}
grant_type: password

// Sample auth request
POST https://login.salesforce.com/services/oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=password&client_id={client_id}&client_secret={client_secret}&username={username}&password={password}{security_token}

// Response includes access_token and instance_url

3Flujos de automatización

          
          

            
🤖 Puntuación de salud de pipeline de IA

            
Puntuar la salud de las oportunidades y marcar oportunidades en riesgo

            

              
              
TRIGGER: Diariamente a las 9:00 AM o cuando se actualizan las oportunidades

WORKFLOW:
1. Query open opportunities:
   GET /services/data/v59.0/query?q=SELECT Id,Name,StageName,Amount,CloseDate,CreatedDate,LastActivityDate,Probability FROM Opportunity WHERE IsClosed=false

2. For each opportunity, calculate health score:
   - Days in current stage (flag if >30 days)
   - Days since last activity (flag if >7 days)
   - Stage vs close date alignment
   - Required fields completion
   - Contact/activity engagement level

3. AI Analysis:
   Prompt: "Analyze this opportunity:
   Name: {{opp.Name}}
   Stage: {{opp.StageName}}
   Amount: {{opp.Amount}}
   Close Date: {{opp.CloseDate}}
   Days in Stage: {{days_in_stage}}
   Last Activity: {{days_since_activity}} days ago
   
   Provide:
   1. Health score (0-100)
   2. Risk factors
   3. Recommended next actions"

4. Update Salesforce:
   PATCH /services/data/v59.0/sobjects/Opportunity/{{id}}
   {
     "Health_Score__c": {{ai_score}},
     "Risk_Factors__c": "{{risk_list}}",
     "Next_Best_Action__c": "{{recommendation}}"
   }

5. Notify rep if health score <50 via Slack/email

            

          


          

            
📈 Actualización automática de categorías de previsión

            

              
              
TRIGGER: Cambios de etapa de oportunidad o revisión semanal

WORKFLOW:
1. Query opportunities by close date & stage:
   GET /services/data/v59.0/query?q=SELECT Id,Name,StageName,CloseDate,Amount,Probability FROM Opportunity WHERE CloseDate=THIS_QUARTER AND IsClosed=false

2. Apply forecast category logic:
   IF CloseDate < 30 days AND StageName IN ('Negotiation', 'Proposal'):
     ForecastCategory = 'Commit'
   ELSE IF StageName IN ('Qualification', 'Needs Analysis'):
     ForecastCategory = 'Pipeline'
   ELSE IF StageName IN ('Proposal', 'Negotiation'):
     ForecastCategory = 'Best Case'
   ELSE:
     ForecastCategory = 'Omitted'

3. Bulk update opportunities:
   PATCH /services/data/v59.0/composite/sobjects
   {
     "allOrNone": false,
     "records": [
       {
         "attributes": {"type": "Opportunity"},
         "Id": "{{id1}}",
         "ForecastCategoryName": "Commit"
       },
       ...
     ]
   }

4. Generate forecast summary report and email to sales leadership

📊 Pipeline Coverage Analysis

            

              
              
TRIGGER: Weekly on Monday 8:00 AM

DATA COLLECTION:
1. Get quota by rep/team:
   GET /services/data/v59.0/query?q=SELECT OwnerId,Owner.Name,SUM(Amount) FROM Opportunity WHERE IsClosed=true AND IsWon=true AND CloseDate=THIS_QUARTER GROUP BY OwnerId,Owner.Name

2. Get open pipeline by rep:
   GET /services/data/v59.0/query?q=SELECT OwnerId,Owner.Name,SUM(Amount) FROM Opportunity WHERE IsClosed=false AND CloseDate=THIS_QUARTER GROUP BY OwnerId,Owner.Name

3. Calculate metrics:
   - Pipeline coverage = Open Pipeline ÷ Remaining Quota
   - Target coverage = 3-4x
   - Gap = Required Pipeline - Current Pipeline

4. Generate report:
   Rep | Quota | Closed | Remaining | Pipeline | Coverage | Gap
   ----+-------+--------+-----------+----------+----------+----
   A   | 500K  | 200K   | 300K      | 750K     | 2.5x     | 150K
   B   | 500K  | 300K   | 200K      | 800K     | 4.0x     | -200K

5. Send to sales leadership with color coding:
   - Green: Coverage >3x
   - Yellow: Coverage 2-3x
   - Red: Coverage <2x
